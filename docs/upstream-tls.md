# 后端证书校验

在“后端服务 → 编辑后端池 → 连接安全”中开启“忽略后端证书校验”，保存草稿并发布后生效。默认关闭，适用于自签名等证书无法通过校验的 HTTPS 后端。

配置字段为后端池的 `skipTlsVerify`，可选布尔值，省略或 false 均保持校验。开启后跳过后端证书可信链、有效期及域名验证；TLS 加密与最低 TLS 1.2 要求保留。该选项不会修复服务端协议不兼容、TLS 握手超时或连接失败。

设置覆盖当前池的全部目标，业务代理、流式连接、WebSocket 和健康探测使用同一策略；采用独立路由超时的连接池也沿用该策略。其他后端池保持各自设置，站点对外证书及未知 SNI 拒绝规则不受影响。

字段随 JSON 草稿、运行配置及版本保存。关闭开关并再次发布后恢复校验，新连接使用新设置；已建立的流式连接与 WebSocket 按现有发布逻辑保持。
