# 站点监听端口

业务端口由用户在站点中设置，不再预设全局 HTTP/HTTPS 端口。管理入口独立，默认 `127.0.0.1:4033`。

## 站点字段

- `httpPort`：1–65535；0 或省略表示关闭 HTTP。
- `https`：是否启用 HTTPS；开启时必须填写 1–65535 的 `httpsPort` 并选择有效证书。
- `httpsPort`：HTTPS 端口，关闭 HTTPS 时为 0 或省略。
- `redirectHttps`：需要同时设置 HTTP、HTTPS 端口；跳转使用该站点的 HTTPS 端口，443 可省略 URL 端口。
- 已启用站点至少设置一个业务协议和端口；停用站点不参与监听。
- `maintenance`：可选布尔值，默认 false。与 `enabled: true` 配合表示关闭站点并展示维护页面，保留监听、域名和证书；`enabled: false` 仍表示停用。

## 关闭站点与维护页面

站点卡片仅展示运行状态，修改时打开“站点配置”，通过运行状态选择正常服务、维护中或停用。维护中表示关闭正常服务，选择正常服务即可恢复。这些操作只修改本地编辑，保存草稿并发布后生效，不删除站点、路由、后端池或证书配置。

维护期间新请求通过原有域名/SNI 和 IP 访问控制后返回 HTTP 503，附带 `Retry-After: 300` 与 `Cache-Control: no-store`，不再跳转 HTTPS 或执行业务路由，也不增加后端池请求/流量统计。HTTPS 仍需覆盖域名的有效证书；同端口其他站点不受影响，未知域名的 TLS 握手仍拒绝。已有长连接保持，HTTP-01 验证入口继续优先处理。恢复服务并发布后使用原有路由配置，进程重启后维护状态从 JSON 恢复。

网关自身对未知 HTTP 站点、未匹配路由和缺失静态资源返回统一中文 404 页面，保留真实 404 状态、请求标识及返回首页入口。维护页提供重新加载入口；两类页面不依赖外部资源，禁止缓存，不回显域名、路径和查询参数。明确请求 `application/json` 且未请求 HTML 时返回 JSON，HEAD 不返回正文。后端服务自己返回的 404 页面仍原样透传。

端口范围包含系统受限端口，但程序不会提权或修改系统配置；权限不足、端口被其他程序或管理服务占用时拒绝发布。业务绑定 IP 默认 `0.0.0.0`，可通过 `serve -listen-host 127.0.0.1` 限制为本机。局域网访问使用服务器实际 IP，不使用 `0.0.0.0` 作为访问地址。

## 多站点共享

相同协议、相同端口只创建一个监听器，通过域名区分站点。例如两个 HTTP 站点可以同时使用 8081；该端口只开放一次。相同域名也可用于不同端口，匹配依据实际接入端口，不信任请求 Host 中自报的端口。

同一端口不允许混用 HTTP 与 HTTPS；同端口重复域名拒绝发布。精确域名优先于单层通配域名。同端口切换协议时，应先发布移除使用该端口的所有站点，再以新协议发布；直接替换会被拒绝，避免抢占在用监听。

## 发布与回收

保存草稿、配置校验不占用业务端口。发布预占新增端口后才提交 JSON；失败释放候选监听，不更改当前配置和现有监听。结果待确认时释放候选端口，确认持久化时重新预占并校验，失败继续保留待确认状态。

提交成功后保留仍被引用的监听，启用新增监听，停止无引用监听接受新连接。正在处理的流式响应和已升级的 WebSocket 继续完成，不因移除监听而立即断开；进程整体关闭仍执行停机超时。回滚也走同样的端口检查，目标端口被占用时不会强行关闭其他程序。

系统设置“当前业务监听”展示实际已激活的协议、地址及共享站点。新实例没有已发布启用站点时，这个列表为空。

## 默认拒绝 TLS 握手

每个 HTTPS 监听均默认具有与 `ssl_reject_handshake on` 对应的保护行为，不需要也不提供逐站点关闭开关：

- 未提供 SNI、未知域名、停用站点、仅 HTTP 站点、只在其他端口配置的域名：握手失败。
- 无有效匹配证书、证书过期或未生效：拒绝握手或在发布校验时阻止启用。
- 没有默认站点或兜底证书，不向未知域名发送其他站点的证书。
- 正常握手后，HTTP Host 与 SNI 站点不一致时返回 421。

业务 TLS 最低为 TLS 1.2，当前禁用会话票据，确保每次新握手重新检查当前端口及域名配置。这里实现的是 Go TLS 的拒绝行为，不依赖 Nginx，也不保证与 Nginx 的 TLS alert 编码完全一致。管理入口仅提供 HTTP；如需 HTTPS，通过站点配置代理至管理入口，启动无需 TLS 参数。

## ACME 与升级

HTTP-01 仍要求公网 80 端口可达挑战路径；先发布含 HTTP 端口的站点，再将公网 80 转发到它，系统不会为签发自动创建隐藏监听。DNS-01 不需要业务 HTTP 监听。

旧启动参数 `-http` / `-https` 已移除，端口必须显式写入站点。旧配置中没有端口的站点需要补充端口后重新校验、发布，不隐式套用旧默认值。旧运行文件、历史快照不能手改以绕过摘要；如果旧实例已经发布了没有站点端口的配置，升级前需备份并安排显式配置转换，不直接启动新程序覆盖旧文件。当前开发数据中无旧已发布站点，无需转换业务端口。
