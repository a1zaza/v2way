# 首版实施状态

当前落实方案 P0/P1 的主要功能闭环，以及部分 P2 能力，包括手动 TLS、ACME、后端健康检查和基础访问策略。v2way 独立开发、部署和验收，相邻项目仅用于前端风格参考。

## 与完整方案的差距

以下项目仍属于后续实施内容，不能以首个开发版本通过测试视为已完成：

1. **P2 证书与恢复**：真实 CA / DNS 账户联调、证书删除及在线凭据修改、完整加密备份和恢复预检、完整崩溃/满盘故障注入矩阵。ACME 流程已通过本地模拟服务测试，未执行真实签发。
2. **日志与诊断**：业务访问日志持久化轮转、日志 SSE 与受控导出、时延直方图、包含协议开销的网络收发字节精确计量（已实现后端池正文及隧道流量统计）。
3. **策略完善**：站点 Basic Auth、受信前置代理 CIDR、每站点连接配额、流式空闲控制（路由总预算及连接/TLS/响应头阶段超时已实现）。目前没有实现方案拟定的七天空闲上限；活动长连接由对端、取消或停机结束。
4. **部署体验**：完整配置差异高亮、独立 URL 的对象详情页（当前使用编辑弹窗）、升级说明自动化。
5. **P3 交付验证**：跨浏览器/真机软键盘与完整无障碍检查、前端发布构建、完整发布包部署验证、同机 Nginx 性能对照和 24 小时稳定性验证。

## 验证方式

- Go 单元与协议集成测试，使用临时数据目录、随机本机端口、模拟后端和临时自签名证书。
- `go test -race ./...` 检查并发访问，覆盖来源头伪造、查询脱敏、路径混淆、静态越界、Range、WebSocket 热发布、SSE 刷新/取消、认证/CSRF、草稿冲突、幂等发布、回滚、持久化失败恢复、主密钥丢失和数据目录独占。
- 前端 TypeScript 检查及 Vitest/jsdom 交互测试，覆盖登录、建站、本地编辑与保存区分、发布确认、保存冲突与校验失败。
- ACME 测试覆盖 HTTP-01、DNS-01 通配符、精确清理、续期、凭据加密/脱敏、请求去重和未知结果恢复；前端补充申请表单及服务商切换测试。
- 当前开发服务已按用户授权启动并允许前端局域网访问。未执行前端生产构建、Docker build 或 Git 操作。
